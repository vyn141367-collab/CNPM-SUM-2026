\section{Actors}
The AI-powered Film Photography Contest Management Platform involves several actors who interact with the system to perform different tasks.
\begin{itemize}
    \item \textbf{Administrator}
    \begin{itemize}
        \item Manages user accounts.
        \item Creates and manages contests.
        \item Reviews submissions and system reports.
        \item Configures contest rules and schedules.
    \end{itemize}
    \item \textbf{Contest Organizer}
    \begin{itemize}
        \item Creates photography contests.
        \item Defines contest requirements.
        \item Reviews participant submissions.
        \item Publishes contest results.
    \end{itemize}
    \item \textbf{Participant}
    \begin{itemize}
        \item Registers an account.
        \item Joins photography contests.
        \item Uploads photographs.
        \item Views contest results and feedback.
    \end{itemize}
    \item \textbf{Judge}
    \begin{itemize}
        \item Reviews submitted photographs.
        \item Scores participant submissions.
        \item Provides comments and feedback.
    \end{itemize}
\end{itemize}
