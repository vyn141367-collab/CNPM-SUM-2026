\section{User Requirements}

\subsection{Actors}

\begin{table}[h!]
\centering
\caption{System Actors and Descriptions}
\label{tab:actors}
\begin{tabularx}{\textwidth}{l X}
\toprule
\textbf{Actor} & \textbf{Description} \\
\midrule
\textbf{Participant} & Users of the platform who create accounts, register film roll technical specs, upload digitized frames, and submit photos to participate in contests. \\
\textbf{Organizer} & Entities or individuals hosting contests. Responsible for creating contests, configuring scoring criteria, assigning Judges, and manually reviewing submissions flagged by the AI. \\
\textbf{Judge} & Photography experts assigned by the Organizer to anonymously evaluate and score submissions based on configured criteria. \\
\textbf{Admin} & System administrator managing master data, approving Organizer accounts, configuring roles/permissions, and overseeing platform operations. \\
\textbf{AI System} & An automated background service actor that scans submissions to detect duplicate images, identify AI-generated content (e.g., Midjourney/DALL-E), and assign classification tags. \\
\bottomrule
\end{tabularx}
\end{table}

\subsection{System Functional Overview}

\subsubsection{Screens Flow}

The PlantUML state diagram below illustrates the navigation flow between system screens across different roles:

\begin{lstlisting}[caption={Screens Flow Source Code (PlantUML)}]
@startuml
hide empty description
skinparam state {
  BackgroundColor White
}

[*] --> LoginScreen : Open Application

state LoginScreen {
  [*] --> Authentication
}

LoginScreen --> AdminDashboard : Role = Admin
LoginScreen --> OrganizerDashboard : Role = Organizer / Manager
LoginScreen --> JudgeDashboard : Role = Judge / Lecturer
LoginScreen --> ParticipantDashboard : Role = Participant / Student

state ParticipantDashboard {
  [*] --> FilmRollsScreen : Manage Photos
  FilmRollsScreen --> FramesDetailScreen : Upload & Select Photo
  ParticipantDashboard --> ActiveContestsScreen : Browse Contests
  ActiveContestsScreen --> SubmitPhotoScreen : Submit Photo
}

state OrganizerDashboard {
  [*] --> ManageContestsScreen : Initialize
  ManageContestsScreen --> SetupCriteriaScreen : Configure Scoring
  ManageContestsScreen --> AssignJudgesScreen : Assign
  OrganizerDashboard --> SubmissionsReviewScreen : Review (AI Alert)
}

state JudgeDashboard {
  [*] --> AssignedContestsScreen : Select Contest
  AssignedContestsScreen --> JudgingPanelScreen : Evaluate
}

state AdminDashboard {
  [*] --> UserManagementScreen
  [*] --> MasterDataScreen
}
@enduml
\end{lstlisting}
